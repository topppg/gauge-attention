# Gauge Attention

Gauge Attention is a small PyTorch research prototype for exploring learned
position-dependent rotary transport in attention.

This repository is being developed as an inspectable reference implementation.
The first public milestones introduce the mathematical transport utilities,
the attention layer, comparison baselines, validation, and explanatory material.

## Status

Early research software. The project does not claim benchmark improvements or
reproduce results from an unpublished paper.
